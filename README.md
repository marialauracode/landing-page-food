## 📂 Sobre o Projeto

* Landing page responsiva desenvolvida como protótipo para uma empresa fictícia de hospedagem de sites chamada hDC Host;
* Criada com HTML5 e CSS3, com foco em praticar estruturação, estilização e responsividade em páginas web;
* O projeto apresenta seções informativas sobre serviços, planos e preços, busca de domínio e formulário de contato;
* Possui campos de entrada (inputs) e botões interativos, porém com finalidade apenas visual, sem integração com banco de dados ou funcionalidades reais;
* Totalmente responsiva, adaptando-se a diferentes dispositivos, como desktops, tablets e celulares.

## 🛠 Tecnologias Utilizadas

* HTML5
* CSS3

## 📦 Funcionalidades

* Design responsivo: a página se adapta a diferentes tamanhos de tela, proporcionando uma boa experiência em qualquer dispositivo;
* Seção de destaque (hero): banner principal com imagem de fundo e chamada de impacto para apresentar a empresa;
* Seção de serviços: exibição dos principais benefícios oferecidos, como segurança, performance e suporte 24/7;
* Planos e preços: área com diferentes opções de hospedagem organizadas em cards informativos;
* Busca de domínio: campo visual para simular a pesquisa de disponibilidade de domínio;
* Formulário de contato: inputs para nome, e-mail e mensagem, permitindo a simulação de envio de solicitações;
* Botões e links estilizados: elementos interativos com efeitos visuais para melhorar a experiência do usuário.
