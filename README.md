## 📂 Sobre o Projeto
Uma landing page responsiva com tema de restaurante, construída com HTML, CSS e JavaScript. Este projeto apresenta um design limpo com animações suaves.

## 🛠️ Tecnologias Utilizadas
* <b>HTML5:</b> Marcação semântica
* <b>CSS3:</b>Estilização
* <b>JavaScript:</b> Funcionalidade interativa
* <b>jQuery:</b> Manipulação DOM e manipulação de eventos
* <b>ScrollReveal:</b> Animações de scroll

## 📦 Funcionalidades
* Layout totalmente responsivo;
* Navegação dinâmica entre as seções;
* Destaque automático da seção ativa no menu (JavaScript);
* Animações de entrada durante a rolagem da página;
* Organização dos produtos em categorias;
* Botões com efeitos de hover e transições;
* Interface moderna e intuitiva.
